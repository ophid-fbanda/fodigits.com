Install

Pick the package listed on the product.

Not every app ships the same way. The product page shows Docker Compose, Linux, and/or Windows. Use only what is listed there.

01

Docker Compose

Where offered: copy .env.example to .env, set LICENSE_KEY, run docker compose up -d. Compose starts the services in that product’s stack.

02

Linux

Where offered: unpack the archive, run the install script in the README, set the license in the env file, start the service with systemd.

03

Windows

Where offered: run the installer, enter the license key, start the app from the Start menu or as a Windows service.

Requirements

Each product page lists CPU, RAM, and which packages exist. Match the host to that list before you download.

After download

Open the README in the package. That file is the source of truth for that build.
