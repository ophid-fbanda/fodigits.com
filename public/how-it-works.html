Deployment

Install with Docker Compose.

Each product ships as a stack: application, database, and reverse proxy. You run it on your VPS or on-prem server.

01

Select product and edition

Open the product page. Choose Home, Pro, or White-label, then Docker Compose (recommended), Linux, or Windows.

02

Download the package

The archive includes docker-compose.yml, .env.example, license terms, and a README with exact commands.

03

Start the stack

Copy .env.example to .env, set LICENSE_KEY and APP_URL, then run docker compose up -d. Open your domain.

What you need

Docker Engine and the Compose plugin. CPU and RAM as listed on the product page. A domain and TLS for public access.

Compose pulls images and starts every service in the stack. You do not install the application runtime on the host.

What’s in the package

docker-compose.yml, environment template, license file, and install notes. Runtime images download on first launch.
